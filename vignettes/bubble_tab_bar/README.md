# Icon Flip Button Bar

An Avalonia port of [bubble_tab_bar](https://github.com/gskinnerTeam/flutter_vignettes/tree/master/vignettes/bubble_tab_bar).

<p align="center"><img src="images/bubble_tab_bar.gif" width="320"/></p>

A navigation bar whose buttons change size, shape and colour as they are picked.

## Running

```
dotnet run --project BubbleTabBar.Desktop/BubbleTabBar.Desktop.csproj
```
