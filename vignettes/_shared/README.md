# _shared

The pieces more than one vignette needs: Flutter's `AnimationController`, `Ticker` and easing curves, a `PageView`, a flex panel, `Hero` flights, perspective transforms, Material icons, a velocity tracker.

Don't add to this directory until a piece has earned its place in more than one vignette.
