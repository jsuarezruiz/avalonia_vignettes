# _shared

The pieces more than one vignette needs: Flutter's `AnimationController`, `Ticker` and easing curves, fractional progress for Avalonia's `Carousel`, a flex panel, `Hero` flights, perspective transforms and Material icons.

Don't add to this directory until a piece has earned its place in more than one vignette.
