# Paris Travel Hero Transition

An Avalonia port of [parallax_travel_cards_hero](https://github.com/gskinnerTeam/flutter_vignettes/tree/master/vignettes/parallax_travel_cards_hero).

<p align="center"><img src="images/parallax_travel_cards_hero.gif" width="320"/></p>

Tap the city card and it opens into a full scene, with the road unrolling from the horizon and the skyline assembling as it grows.

## Running

```
dotnet run --project ParallaxTravelCardsHero.csproj
```
