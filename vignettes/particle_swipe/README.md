# Inbox Swipe Particles

An Avalonia port of [particle_swipe](https://github.com/gskinnerTeam/flutter_vignettes/tree/master/vignettes/particle_swipe).

<p align="center"><img src="images/particle_swipe.gif" width="320"/></p>

Swipe a row left to delete it and it bursts into particles; swipe right to star it and the burst opens as a ring.

## Running

```
dotnet run --project ParticleSwipe.Desktop/ParticleSwipe.Desktop.csproj
```
