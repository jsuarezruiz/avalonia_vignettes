# Article Dark Mode

An Avalonia port of [dark_ink_transition](https://github.com/gskinnerTeam/flutter_vignettes/tree/master/vignettes/dark_ink_transition).

<p align="center"><img src="images/dark_ink_transition.gif" width="320"/></p>

Ink spreads across the article to carry it between the light and dark schemes, masked by a frame sequence.

## Running

```
dotnet run --project Desktop/DarkInkTransition.Desktop.csproj
```
