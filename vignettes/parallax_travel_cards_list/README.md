# Travel Cards

An Avalonia port of [parallax_travel_cards_list](https://github.com/gskinnerTeam/flutter_vignettes/tree/master/vignettes/parallax_travel_cards_list).

<p align="center"><img src="images/parallax_travel_cards_list.gif" width="320"/></p>

Drag through the cards and the three artwork layers slide past each other while the card itself tilts in 3D.

## Running

```
dotnet run --project ParallaxTravelCardsList.csproj
```
