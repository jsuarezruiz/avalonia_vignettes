# Fluid Button Bar

An Avalonia port of [fluid_nav_bar](https://github.com/gskinnerTeam/flutter_vignettes/tree/master/vignettes/fluid_nav_bar).

<p align="center"><img src="images/fluid_nav_bar.gif" width="320"/></p>

The bar's top edge dips under whichever button is picked, and sloshes as that dip travels across.

## Running

```
dotnet run --project FluidNavBar.Desktop/FluidNavBar.Desktop.csproj
```
