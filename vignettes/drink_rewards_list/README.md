# Liquid Rewards Cards

An Avalonia port of [drink_rewards_list](https://github.com/gskinnerTeam/flutter_vignettes/tree/master/vignettes/drink_rewards_list).

<p align="center"><img src="images/drink_rewards_list.gif" width="320"/></p>

Tap a card and it springs open, then fills with liquid that sloshes as it settles. How far it fills depends on whether you have the points for that drink.

## Running

```
dotnet run --project Desktop/DrinkRewardsList.Desktop.csproj
```
