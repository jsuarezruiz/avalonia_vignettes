# Feature Artist Carousel

An Avalonia port of [indie_3d](https://github.com/gskinnerTeam/flutter_vignettes/tree/master/vignettes/indie_3d).

<p align="center"><img src="images/indie_3d.gif" width="320"/></p>

Swipe between artists while a field of 3D shapes drifts behind and in front of them. Tapping shoves the shapes away and sets them spinning.

## Running

```
dotnet run --project Desktop/Indie3D.Desktop.csproj
```
