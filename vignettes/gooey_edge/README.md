# Mindfulness Gooey Transition

An Avalonia port of [gooey_edge](https://github.com/gskinnerTeam/flutter_vignettes/tree/master/vignettes/gooey_edge).

<p align="center"><img src="images/gooey_edge.gif" width="320"/></p>

Swipe between pages and the incoming one is revealed through a liquid edge that follows the pointer, run by a small spring simulation.

## Running

```
dotnet run --project GooeyEdge.csproj
```
