# Sports App Pull To Refresh

An Avalonia port of [basketball_ptr](https://github.com/gskinnerTeam/flutter_vignettes/tree/master/vignettes/basketball_ptr).

<p align="center"><img src="images/basketball_ptr.gif" width="320"/></p>

Pull the scores down and a basketball spins around the hoop while they reload.

## Running

```
dotnet run --project BasketballPullToRefresh.csproj
```
